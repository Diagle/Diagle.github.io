# Diagle 个人网站部署说明

1. 解压 ZIP 文件。
2. 打开 `Diagle/Diagle.github.io` 仓库，选择 **Add file → Upload files**。
3. 上传解压目录中的 `index.html`、`assets/` 文件夹和本说明文件（不要把外层文件夹整体嵌套上传）。
4. 点击 **Commit changes**。
5. 在仓库 **Settings → Pages** 中选择从 `main` 分支根目录发布。
6. 等待部署完成后访问 https://diagle.github.io/ 。

注意：这是基于已知公开仓库信息制作的网站模板，项目描述应以每个仓库实际 README 和代码为准。请勿将数据、凭据或其他敏感文件发布到公开站点。
